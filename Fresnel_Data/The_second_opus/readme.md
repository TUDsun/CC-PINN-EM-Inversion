# Measured Datasets (`Fresnel_Data`)

## Description
This folder contains a formatted version of the `FoamTwinDielTM` experimental dataset. We processed the original data slightly to fit the input format of our PyTorch implementation.

## Acknowledgement & Copyright
The original experimental data was measured and provided by the **Institut Fresnel, Marseille, France**. We do NOT own the copyright to this data.

If you use this dataset, you **MUST** cite the original paper that published it, in addition to our algorithmic paper:
> J.-M. Geffrin, P. Sabouroux, and C. Eyraud, "Free space experimental scattering database continuation: experimental set-up and measurement precision," Inverse Problems, vol. 21, no. 6, pp. S117–S130, 2005.

The original datasets can be found at the Institut Fresnel official repository.
