# Simulated Datasets (`Data_Sim`)

## Description
This folder contains the simulated electromagnetic scattering data (TM polarization) used in the paper. The datasets include various contrasts and noise levels (20dB, 10dB, 0dB SNR) for the "Austria" and "Bowtie-Cross" targets.

## Usage & Citation
These datasets are provided for reproducing the results of our paper. If you use these datasets in your own research, please strictly cite our paper:
> Shilong Sun, "Beyond Data-Physics Consistency: A Cross-Correlated Physics-Informed Neural Network for Robust Inverse Scattering", IEEE Transactions on TAP, 2026.
